# ARSA
**Audio Resonant Streaming Architecture**

A free, ad-free music player for Android.<br>
No account. No ads. No limits.

---

ARSA streams the entire YouTube Music catalog with a **Liquid Glass** interface — real-time frosted glass, spring animations, and artwork-reactive color theming. Everything is on-device. Nothing is tracked.

**Synced lyrics** from multiple sources, word-by-word karaoke highlighting. **Built-in equalizer** with custom presets. **Offline downloads**. **Last.fm scrobbling**. **Listen Together** sessions. **Chromecast** support.

Requires Android 8.0 or higher.
